# Home Accounting System

A centralized family accounting management system that helps families track income, expenses, budgets, and financial activities.

The system allows multiple families to create accounts, manage family members, assign budgets, record expenses, and get AI-powered financial insights.

-----------------------------------------------------------------------------

# Features

## Family Management

- Multiple family accounts
- Family owner becomes administrator
- Admin can add family members
- Role-based access control
